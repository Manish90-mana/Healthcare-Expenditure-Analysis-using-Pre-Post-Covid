# Healthcare Expenditure Analysis Before and After COVID-19

## Project Overview

This project investigates changes in healthcare expenditures and the financial burden experienced by individuals and families in the United States before and after the COVID-19 pandemic.

Using data from the **Medical Expenditure Panel Survey – Household Component (MEPS-HC) for 2019 and 2021**, the project analyzes healthcare expenditure patterns, insurance-related factors, and differences in financial burden across population groups.

The study applies Python-based data analysis and machine learning techniques to process healthcare datasets, identify meaningful patterns, and explore the factors associated with healthcare expenditure. A Random Forest model is also implemented as part of the predictive analysis.

Additionally, the project incorporates an **insurance eligibility chatbot** designed to provide information about insurance eligibility based on user-provided information and income categories.

## Objectives

- Analyze healthcare expenditure patterns before and after COVID-19.
- Examine changes in the financial burden associated with healthcare expenses.
- Investigate differences across income groups and insurance-related categories.
- Clean, preprocess, validate, and integrate MEPS-HC datasets.
- Apply exploratory data analysis to identify important trends and relationships.
- Develop a Random Forest machine learning model for predictive analysis.
- Build an insurance eligibility chatbot to improve awareness of potential insurance coverage options.

## Dataset

**Source:** Medical Expenditure Panel Survey – Household Component (MEPS-HC).

- 2019 MEPS-HC: Pre-pandemic healthcare expenditure data.
- 2021 MEPS-HC: Post-pandemic healthcare expenditure data.

The datasets provide information about healthcare utilization, medical expenditures, insurance coverage, and demographic characteristics.

Official dataset source: https://meps.ahrq.gov/

## Methodology

1. **Data Collection:** Obtain relevant healthcare expenditure datasets from MEPS-HC for 2019 and 2021.
2. **Data Preprocessing:** Perform data cleaning, missing-value handling, data validation, and feature preparation.
3. **Exploratory Data Analysis:** Examine healthcare expenditure distributions and patterns across different population and income groups.
4. **Feature Engineering:** Prepare relevant features for machine learning analysis.
5. **Predictive Modeling:** Implement a Random Forest model to explore patterns and predict the selected target variable.
6. **Insurance Eligibility Chatbot:** Develop a chatbot that uses user-provided information and income categories to provide insurance eligibility-related guidance.
