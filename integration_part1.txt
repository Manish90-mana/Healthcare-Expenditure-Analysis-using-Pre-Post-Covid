## 3. Remove or rethink `medians.pkl`

This means the chatbot is filling missing fields with defaults.

That is okay only if:

* those columns are truly required by the model
* and median-fill is exactly what your official training pipeline does

Otherwise, it becomes inconsistent.

### Better options:

#### Option A

Ask the user for those fields too, if they are important.

#### Option B

Use a preprocessing pipeline saved from training that automatically imputes missing values.

#### Option C

Retrain the model using only features you actually want the chatbot to collect.

For a presentation/demo, Option C is often best:
train the model on a smaller, interpretable set of fields that the chatbot can reasonably ask.

## 4. Replace hardcoded ZIP resource dictionary with a CSV

This part is separate from MEPS, but should still be changed.

Instead of:

```python
resource_db = {
    "76010": [...],
    "10001": [...]
}
```

use:

```python
resources_df = pd.read_csv("data/zip_to_resources.csv")
```

and:

```python
def get_resources(zip_code):
    matches = resources_df[resources_df["zip_code"].astype(str) == str(zip_code)]
    if matches.empty:
        return None
    return matches.to_dict(orient="records")
```

This makes the chatbot compatible with your project structure.
